Cos Nostra — desktop clipper

A warm, sober tool for one Discord of friends. Paper-and-ink palette, one tomato accent, no gamer chrome. Screens alternate light and dark below — both themes run on the same token set and follow the system theme.

1aNavigation model & window sizing
Three places, one glance

Tabs: Library · Storage · Settings. Capture status is not a tab — it is a live pill in the toolbar, always visible ("is it recording?" answered without navigating). Clicking it opens the status panel (1h). The player is a detail view inside Library (1e), not a destination.

Sizing

Default 1120 × 720, resizable, minimum 720 × 520. Clip grid is fluid (minmax(196px,1fr)). Below ~840 px the game sidebar folds into a dropdown (1j) so the app stays pleasant parked on a second monitor. Large sizes just show more grid columns — nothing stretches.

Errors surface upward

Recorder failure, stolen hotkey and missing ffmpeg stack as banners under the toolbar on every tab, and repeat with detail inside the status panel. Per-clip failures stay on the clip. Closing the window hides to tray; the first close shows a one-time toast (1k).
